カスタムビンゴ

好きなお題で、みんなでビンゴ。

数字だけじゃない、自由なお題で遊べるビンゴアプリ。
使い方は無限大。イベントや動画の企画でもご利用いただけます。

特徴

  • 好きな言葉でビンゴのお題リストを自由に作成
  • 作ったリストはテキストでかんたん共有
  • リストからビンゴカードを自動生成
  • 司会者モード：生成したリストからカンタン抽選
  • オフライン完結。通信不要でどこでも遊べる

遊び方の例

  • 麻雀で：アガった役でビンゴ
  • しりとりで：使った文字でビンゴ
  • カラオケで：出た点数でビンゴ
  • 忘年会・新年会で：社内のあるあるネタや流行語をお題にビンゴ
  • 勉強で：英単語や専門用語の聞き取りビンゴ
  • 家族で：好きな食べ物や動物の名前で、子どもと一緒にビンゴ

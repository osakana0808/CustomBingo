カスタムビンゴ

好きなお題で、みんなでビンゴ。

数字だけじゃない、自由なお題で遊べるビンゴアプリ。
結婚式の二次会、忘年会、オフ会、授業まで。サーバー不要・オフラインで完結します。

自由なリスト作成

好きな言葉でビンゴのお題リストを作成。ひらがな・アルファベット・麻雀の役などのプリセットも収録。

カード自動生成

3×3 / 4×4 / 5×5 のカードをランダム生成。参加者は各自の端末でタップしてマーク。

司会者モード

ガラガラ抽選アニメーションと抽選履歴で、イベントの進行を盛り上げます。

かんたんシェア

作ったリストはテキストでコピーして共有。受け取った人はそのまま読み込めます。
